# DoggyLog 激励闭环需求基线｜统一陪伴成长、徽章里程碑与奖励回滚

> 对应飞书文档：https://bytedance.larkoffice.com/docx/JqWpd3t8aox1THxj2nNcbQ7PnYg
>
> 本文件作为项目内 Markdown 摘要；完整可评审版本以飞书文档和同目录 XML 源稿为准。

## 已确认决策

- 统一陪伴成长：所有外观主题共享一套经验、等级、连续完成和徽章；切换外观不改变成长进度。
- 徽章与里程碑：等级提升先兑现为徽章、称号和下一目标，不新增免费成长外观，不改变付费主题权益。
- 撤销扣回：取消完成时扣回对应经验，重算连续、等级和徽章；重复勾选不能刷分。

## 当前代码断点

| 环节 | 当前状态 | 断点 |
|---|---|---|
| 任务关联 | 完整新建页写入当前 petId；旧编辑弹层保存时固定 petId=null | 编辑后可能丢失伙伴关联 |
| 发奖 | 仅 task completed 且 petId 非空时加分 | 无 petId 任务不发奖，且用户不可感知 |
| 经验 | 基础 10 分，连续 3/5/7 天加 5/8/12 分 | 经验挂在具体 PetProfile，上切换外观导致进度跳变 |
| 防刷 | 重复 true 可重复插入流水；false 不扣回 | 可刷分、不可逆、账目不一致 |
| 等级 | points ~/ 100 + 1 | 只展示数字，没有下一等级进度 |
| 皮肤 | PetSkin.unlockLevel 只存在于示例配置 | 等级换装未实现，且与付费皮肤冲突 |
| 反馈 | TaskCompletedEvent 已发出 | 未承接为经验/升级/徽章反馈 |
| 心情 | deriveMood 根据逾期和今日完成率计算 | 仍为被动状态，本版不扩大改造 |

## P0 最小闭环

1. 新增唯一 CompanionGrowth 账户，保存总经验、等级、连续信息和迁移版本。
2. GrowthLedger 记录任务、日期、基础经验、连续加成、流水状态和回退原因。
3. 本地有效任务完成时幂等发奖；同步系统任务默认不直接发奖。
4. 基础经验 10 分；连续 3-4 天 +5，5-6 天 +8，7 天及以上 +12；每 100 经验升 1 级。
5. 完成后展示经验浮层；升级或获得徽章时展示庆祝反馈。
6. 首页陪伴卡片展示等级、经验进度、下一等级和连续天数。
7. 取消完成或删除已完成任务时，在同一事务中作废流水、重算连续、总经验、等级和徽章。
8. 修复旧编辑弹层保存 petId=null 的问题，编辑历史任务日期时触发连续重算。
9. 从现有多 PetProfile 迁移：优先用有效流水合计校验，流水不可信时取最高宠物积分；迁移幂等。
10. P0 徽章：Lv3 认真陪跑员、Lv5 习惯搭子、Lv7 默契伙伴、Lv10 亲密家人；连续 3 天和 7 天各一个徽章。

## 明确不做

- 不做多宠物独立成长。
- 不做免费等级外观，不启用 unlockLevel 自动换装。
- 不改付费主题商品、价格和恢复购买。
- 不给倒计时庆祝发经验。
- 不做服务端账号、跨设备同步和排行榜。

## 关键验收

- 首次完成本地任务：任务完成、经验 +10、首页进度刷新、反馈可见。
- 连续第三天完成：总奖励 +15，流水记录 streak=3 和 +5 加成。
- 重复勾选已完成任务：不新增流水、不重复加分、不重复弹窗。
- 取消完成：奖励作废，经验、连续、等级和徽章回到应有状态。
- 删除已发奖任务：按取消完成扣回，并在删除确认中说明。
- 切换外观：成长值、等级、连续和徽章保持不变。
- 旧编辑入口保存：原 petId 不被清空。
- 迁移重复启动：成长值不重复加总。

## 验证说明

本需求基于本地源码静态阅读整理。尝试运行 Flutter 聚焦测试时，本机 pub 缓存中的 meta / async / file / glob 等依赖解析异常，导致 kernel 生成失败；研发前需先修复依赖缓存，再按飞书文档中的完整测试清单补回归。
