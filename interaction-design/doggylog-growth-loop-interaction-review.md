# DoggyLog 激励闭环交互设计 · 审阅说明（修订版）

## 交付与边界

打开同目录的 `doggylog-growth-loop-interaction-prototype.html`，可直接使用 Chrome / Safari。图片已内嵌，不依赖外部网络资源。左侧为手机交互，右侧（手机上位于下方）为审阅场景选择器。

本轮仅交付需求与交互设计；Flutter 开发已停止，仓库中此前的部分未验证代码保留，App 尚未实现完整交互。原型未连接真实数据库、系统日历、通知、支付或用户账户，数据仅保存在页面会话中，刷新即可重置。

## 本版修订原则

根据审阅意见，本版不重构现有 App：

- **日历页不加成长卡**：保留原来的日期区、日程列表、右上角宠物入口和新增入口。
- **成长只放在“我的”页顶部**：与宠物形象、换装入口合并成一张宠物卡，点成长区后再展示成长详情、徽章和经验明细。
- **按本轮确认合并换装区域**：原“毛孩子／给小狗换装”独立区域收起，换装功能迁到顶部卡片；下方直接衔接原“设置”分组，周一开始、轻震反馈、通知提醒、生物识别、语言、系统日历、字体大小、恢复购买、关于均保留。
- **不新增底部 Tab**：仍保留“倒计时 / 日历 / 我的”。
- **付费主题不与等级挂钩**：外观切换仍走现有购买权益逻辑，成长卡只展示统一经验。

> 当前源码的正式“我的”页未包含开发调试入口，因此本交互稿不新增该入口。此稿用于交互审阅，不作为原生 App 的像素级还原或已实现产品。

## 建议审阅路径

默认使用“升级与徽章”模拟数据，打开时先展示“我的”页，方便审阅本轮增量。点击底栏“日历”可检查未增加成长卡的日历页。

1. 在“我的”页查看顶部合并卡，点右侧“换装”进入外观页，返回后点下方“成长详情”进入成长页，确认两个入口不会混淆。
2. 顶部卡下方直接接设置区，向下滚动确认原设置项和顺序仍在。
3. 进入成长详情，可继续查看徽章墙或经验明细。
4. 回到日历，勾选任一本地日程。初始 190 经验、Lv2、昨日连续 2 天；完成后获得 15 经验（基础 10 + 连续 5），变为 205 经验、Lv3、连续 3 天。
5. 再点该日程勾选，查看撤销影响预览：205 → 190、Lv3 → Lv2、连续 3 → 2，等级徽章和连续徽章将回到未达成。
6. 确认取消后回退；重新完成只恢复一笔奖励，避免重复刷分。

## 页面与交互决定

### 日历页

- 不新增成长卡、徽章入口或经验提示入口。
- 保留日程左侧完成热区；完成后的奖励反馈以浮层 / Toast 出现，但不改变日历信息架构。
- 系统日历任务可标记完成，但不发成长经验；本轮不扩展其奖励范围。

### 我的页

- 顶部宠物卡上半部展示形象、名称、当前外观；右侧“换装”按钮进入原外观页。
- 下半部展示等级、称号、本级进度、下一等级目标与连续／最长／徽章摘要；整个下半区可点击进入“陪伴成长”，并显示明确的“成长详情”文案。
- 卡片容器不整体可点，换装与成长按钮互不嵌套，避免误触；下方不再单列“毛孩子／给小狗换装”区域。
- 仅合并入口和视觉承载，成长数据、等级和付费主题权益不合并、不互相解锁。
- 原设置项顺序与控件类型保留；通知提醒仍为开关，字体选项与恢复购买按钮仍在同一设置卡内。未改动的设置只给“沿用当前 App”演示反馈，不连接真实系统功能。

### 奖励反馈

- 普通完成仅轻提示；升级与新徽章合并为一张庆祝卡，不连续弹多层。
- 奖励无需领取，完成即入账。
- 本地写入中保持原任务状态不变，失败时可重试。

### 撤销、删除与编辑

- 取消完成或删除已发奖任务前，先展示经验、等级、连续和徽章的准确变化。
- 修改已完成任务的计划日期不改变实际完成日和成长奖励，不额外弹成长影响确认；标题等编辑不发奖。
- 撤销后重新完成只能恢复对应一笔奖励。

## 场景覆盖

原型提供 8 个审阅场景：升级与徽章、普通完成、历史撤销、一周陪伴、新用户空态、完成失败、切换外观、成长迁移提示。迁移提示仅用于说明用户感知，不模拟真实数据库迁移。

## 已确认的最终规则

连续按实际完成动作发生的本地自然日统计，连续加成每天只发一次，各本地任务仍获得基础10经验。编辑计划日期不移动完成日。当天仍有其他有效完成记录时，取消任务只净扣对应基础10，当日加成转移；当天最后一条撤销时，重算后续连续、经验与徽章。

配套需求定稿为 `../docs/plans/2026-10-27-growth-loop-requirement-baseline.md`。旧飞书及旧 XML 只作历史参考。

## 已执行验证

已在桌面 1440×900 和移动 390×844 两种宽度自动执行主路径：

“日历不加成长 → 顶部合并宠物卡：换装与成长独立点击 → 原设置项保留 → 完成 → 升级与徽章 → 撤销扣回 → 恢复”。

验证结果：全部断言通过；无控制台错误、资源错误、横向溢出或未绑定按钮。已人工查看桌面与移动端截图。其余业务分支为共同状态逻辑审阅，真实 iOS App、小组件、数据库迁移与支付不在本轮验证范围。
